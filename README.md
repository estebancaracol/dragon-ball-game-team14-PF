# dragon-ball-game-team14-PF
Juego para el proyecto final basado en Dragon ball, episodio 18 Entrenando al estilo de Roshi

🎮 Controles del Juego
El juego cuenta con tres niveles, cada uno con mecánicas y controles específicos. A continuación, se detalla cómo interactuar con el personaje Goku en cada nivel:

🧩 Controles Generales
Esc: Volver al menú principal.

Movimiento continuo: Las teclas de movimiento (A, D, W, S) son gestionadas mediante un sistema de teclas presionadas que permite movimiento fluido mientras se mantienen presionadas.

🌟 Nivel 1: Plataformas básicas
A: Moverse a la izquierda.

D: Moverse a la derecha.

Espacio: Saltar (si no está ya saltando o nadando).

🔥 Nivel 2: Disparos con parábola
A / D: Moverse lateralmente.

W: Aumentar fuerza del disparo.

S: Disminuir fuerza del disparo.

Q: Disminuir ángulo del disparo.

E: Aumentar ángulo del disparo.

C: Alternar visualización de trayectoria del disparo.

Z: Disparar proyectil recto.

X: Disparar proyectil parabólico.

Espacio: Saltar (si no está ya saltando o nadando).

🌊 Nivel 3: Mecánica de nado
A / D: Nadar lateralmente (si está en modo nado) o moverse sobre superficie.

W: Nadar hacia arriba.

S: Nadar hacia abajo.

Si Goku no está nadando, se comporta como en el Nivel 1 (plataforma tradicional).
